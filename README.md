# 研学实操资源编排

把分组、资源、活动、行程修订和学习证据事件串成可执行的实验编排，并提供一条多馆延误事件流的确定性重放命令入口。

## 命令入口：确定性重放

```bash
node src/replay.js data/multi-venue-delay.json [--checkpoint 路径] [--report 路径] [--stop-after N] [--reset]
```

- 输出每个小组的改线原因、当前资源余量（场馆窗口/设备/指导员/耗材批次）和仍有效的学习证据。
- 检查点默认放在系统临时目录（按事件流路径派生），可用 `--checkpoint` 指定。
- 进程中断（或用 `--stop-after N` 模拟）后再次运行同一命令，自动从未完成检查点继续，结果与一次跑完逐字节一致。
- 事件流任何字段被改动后，检查点指纹不匹配，拒绝续跑（避免在错位的快照上继续记账）。

## 领域规则（引擎强制）

1. **活动声明**：人数、技能前置、耗材批次、安全等级先行声明。
2. **分组确认后才预占**：设备、指导员、场馆时间窗的预占在分组确认前一律拒绝。
3. **高风险学生替代方案**：须安全教师签署，且替代活动安全等级必须降低；不得为简化排程取消整组。
4. **延误只迁移后续**：已开始的环节与其实际消耗保留不回补，只迁移未开始的安排。
5. **公平候补**：冲突场次按 安全等级 → 原计划场次 → 分组确认时间 → 组编号 的顺序候补，窗口释放时队首自动转正。
6. **易耗品不重复返还**：预占行是状态机（reserved → consumed | released），每行只流转一次。
7. **回执幂等与异文**：相同编号+相同内容的重传不重复入账；同编号内容变化时原证据失效，依赖它的后续环节暂停。

## 样例事件流

`data/multi-venue-delay.json` 覆盖：A馆延迟开放、B馆分流、显微设备在途、高风险学生替代签署、两组公平候补、耗材消耗与一次性返还、回执相同重传与同编号异文暂停。
